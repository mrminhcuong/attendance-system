# Hệ Thống Điểm Danh Sinh Viên Bằng QR Code

Ứng dụng web điểm danh sinh viên sử dụng mã QR, hỗ trợ 1000 sinh viên.

## Tính năng
- 📱 Quét mã QR để điểm danh
- 🔒 Nhận diện thiết bị tự động (chỉ cần nhập mã SV lần đầu)
- 👨‍💼 Trang quản trị Admin: CRUD sinh viên, môn học, buổi học
- 📊 Báo cáo điểm danh, xuất CSV

## Cài đặt local

```bash
npm install
npm start
```

Truy cập: http://localhost:3000
